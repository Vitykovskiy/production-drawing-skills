# Рабочие чертежи из CAD

Навык **prepare-production-drawings** для выпуска лаконичного комплекта, по которому человек может изготовить, собрать и проверить изделие. Основной профиль — мебель, деревянные детали и присадка. Поддерживается отдельный режим формального оформления по выбранным редакциям ЕСКД.

## Что делает

- Получает размеры из модели, связывает позиции, спецификацию и карточки деталей.
- Выбирает минимально достаточные виды, разрезы и размеры; объединяет одинаковые детали.
- Показывает рабочие грани и базы; проверяет посадки, конечные зазоры и порядок сборки.
- Отделяет неподтверждённые производственные решения от согласованных данных.
- Убирает пустые таблицы, служебную историю и повторные пояснения.
- Требует просмотра каждого листа PDF в целевом формате и без цвета.

Навык использует имеющуюся CAD-систему. Он не является новым геометрическим ядром, универсальным конвертером STEP→ЕСКД или сертификатом соответствия. CAD-генератор подбирается под исходную модель. Формальный профиль требует проверки всех применимых стандартов проекта.

## Установка для пользователя

Скопировать **весь** каталог `skills/prepare-production-drawings`, сохранив вложенные файлы, в каталог навыков агента. Для актуального Codex: `~/.agents/skills/prepare-production-drawings`; для Claude Code: `~/.claude/skills/prepare-production-drawings`. Для другой среды проверить её официальную документацию. Существующий одноимённый навык сначала сохранить и сравнить.

Инструкции навыка сами по себе не требуют Python-пакетов. Для вспомогательного контроля PDF нужны Python 3.10+, зависимости из `skills/prepare-production-drawings/requirements.txt` и, для рендера, Poppler с командой `pdftoppm`. Устанавливать Python-зависимости в отдельную среду:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r skills/prepare-production-drawings/requirements.txt
.venv/bin/python skills/prepare-production-drawings/scripts/pdf_preflight.py drawing.pdf \
  --json qa/preflight.json --render-dir qa/pages --dpi 150
```

В Windows использовать `.venv\Scripts\python.exe`. Poppler устанавливается отдельно из подходящего доверенного источника для ОС. Если рендерер отсутствует, навык допускает имеющийся PDF-просмотрщик с ручной проверкой всех листов; пропуск проверки отмечается явно.

Коды скрипта: `0` — перечисленные проверки выполнены, возможны предупреждения; `1` — ошибки или неполная проверка; `2` — неправильные аргументы. Скрипт проверяет извлечённый текст и границы страницы, не все визуальные коллизии, размерные цепи или ГОСТ. Размер шрифта в пунктах не является высотой прописной буквы.

## Использование

> Используй $prepare-production-drawings. На основании этой модели подготовь рабочий комплект для столярной мастерской. Профиль workshop, русский язык, миллиметры. Определи минимально достаточный состав листов, покажи базы и стороны присадки, объедини одинаковые детали. Сверь соединения и просмотри каждый лист PDF. Неустановленные производственные требования перечисли отдельно; исходную конструкцию меняй только в рамках задачи.

Для формального комплекта указать `formal_eskd`, применимые требования предприятия и редакции стандартов. Для ревью PDF модель необязательна, но соответствие модели тогда остаётся непроверенным.

## Проверки пакета

Проверены метаданные Agent Skills, работа PDF-скрипта на 25-листовом документе и синтетические случаи: повороты страниц, CropBox/MediaBox, мелкий текст, выход за границы, отсутствие извлекаемого текста и отсутствие рендерера. Процесс навыка отдельно применён агентом к исходному PDF без предыдущих замечаний в контексте. Генерация нового комплекта из 3D-модели в этой проверке не выполнялась: исходная модель не предоставлялась.

Для воспроизведения тестов:

```bash
.venv/bin/python -m pip install -r requirements-test.txt
.venv/bin/python -m unittest discover -s tests -v
```
