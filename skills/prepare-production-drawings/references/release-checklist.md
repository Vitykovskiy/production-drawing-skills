# Проверка выпуска

Фиксировать результат отдельно от рабочих листов: **проверено / не применимо / открытый вопрос**, с основанием. Для отсутствующей проверки сохранять действительный статус. Длинный отчёт не требуется.

## А. Производственная достаточность

| Проверка | Критерий |
|---|---|
| Источник | Названы модель/версия/единицы; критические размеры сопоставлены с источником |
| Состав | Позиции, количество экземпляров и уникальные карточки согласованы со спецификацией |
| Группирование | Карточки сопоставлены по готовой детали и обработке после допустимого поворота; одинаковые объединены, сборочные позиции и различия сохранены |
| Ориентация | Видны рабочая грань, база, направление отсчёта и связь левой/правой детали со сборкой |
| Размеры | Достаточны для изготовления/контроля; повторные и справочные значения различены |
| Отверстия | Заданы количество, положение, диаметр, грань входа, тип и смысл глубины; сопряжения совместимы |
| Посадки | Для функциональных зазоров/натягов есть знаковая цепь, диапазон с учётом всех звеньев и покрытия, допустимый результат и способ контроля; неизвестные звенья явно открыты |
| Сборочные размеры | На схемах видны обе поверхности зазора, конечный габарит склеиваемого/подвижного узла и необходимые связи между его деталями |
| Материалы | Существенные материал, ориентация, кромки, клей, отделка и покупные изделия определены |
| Сборка | Крепёж распределён по стыкам; последовательность выполнима; необходимые детали замыкаются вовремя |
| Применимость | Отсутствуют неприменимые операции; для пошива/закупки определены готовые размеры, крепления/петли и их привязка к сборке |
| Приёмка | Для важных функций заданы проверяемые требования; статус нагрузки/устойчивости соответствует доказательствам |

## Б. Фактический PDF

| Проверка | Критерий |
|---|---|
| Формат и масштаб | Формат, масштаб и проекция соответствуют экспортированным видам и печати |
| Виды | Минимально достаточны; одинаковые торцы обозначены общей схемой при однозначности; разрывы обоснованы форматом; мелкая присадка видна в укрупнении |
| Надписи | Читаются на бумаге; не обрезаны, не перекрывают другие надписи, стрелки и нужные контуры |
| Линии | Контуры, скрытые линии, оси и штриховка различимы без цвета |
| Таблицы | Есть данные; номера связаны с геометрией; заголовки и единицы однозначны |
| Навигация | В перечне есть лист/ссылка на карточку; обозначения, редакция и номера листов согласованы |
| Содержание | Сборка разбита на короткие нумерованные операции; вопросы согласования отделены; критичные производственные напоминания сохранены |
| Экспорт | Все листы открываются; символы воспроизводятся; после изменения модели нет устаревших видов |

## Как применять pdf_preflight.py

Требования: Python 3.10+, `pdfplumber`; для PNG — Poppler (`pdftoppm`). Python-зависимости устанавливать в отдельную среду либо использовать существующую. Проверенная версия `pdfplumber`: 0.11.9.

```bash
python <skill-dir>/scripts/pdf_preflight.py drawing.pdf \
  --json qa/preflight.json --render-dir qa/pages --dpi 150 --warn-below-pt 9
```

Порог в пунктах — эвристика поиска мелкого текста, а не проверка высоты буквы по ГОСТ. Отсутствие извлечённого текста не означает пустой лист: буквы могут быть контурами или изображением.

Просмотреть цветные и серые PNG. Отчёт использовать для поиска мест, требующих внимания; проверить каждое замечание. Отсутствие автоматических ошибок не доказывает отсутствие наложений, полноту размеров, прочность или соответствие ЕСКД.

## Краткая запись результата

```text
Источник: <модель и версия/хеш>; единицы: <...>.
Комплект: <редакция>, <число листов>, <формат печати>.
Профиль: workshop / formal_eskd; применимые стандарты: <...>.
Проверено: <геометрия/стыки/количества; все листы и серый вывод>.
Открыто: <конкретные сведения, влияющие на выпуск, или «нет»>.
Статус: для согласования / готово к изготовлению в согласованном объёме.
```

Закрывать критичные вопросы перед окончательным выпуском. Для результата только в пределах оформления обозначать этот объём проверки; не подменять его утверждением полной пригодности конструкции.
