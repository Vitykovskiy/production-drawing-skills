# Промпт для агента на целевой машине

Установи навык `prepare-production-drawings` из репозитория `https://github.com/Vitykovskiy/production-drawing-skills` глобально для текущего пользователя, чтобы он был доступен во всех проектах. Выполни установку и проверку, а не только выдай команды.

1. Определи ОС и используемый агент. Прочитай README, SKILL.md и скрипты репозитория. Сохрани копию репозитория в постоянном пользовательском каталоге и запиши установленный commit SHA. Используй существующую авторизацию GitHub; если доступ закрыт, назови конкретный необходимый шаг авторизации.
2. Установи весь каталог `skills/prepare-production-drawings` вместе с `references`, `scripts`, `agents` и `requirements.txt`. Для актуального Codex пользовательский каталог — `~/.agents/skills`; для Claude Code — `~/.claude/skills`. Для другого агента/старой версии сначала проверь его правила. Глобальная установка означает область текущего пользователя, а не изменение системных каталогов всех пользователей.
3. Сохрани существующие навыки и настройки. Если навык с таким именем уже есть, сравни его с репозиторием и сохрани резервную копию перед обновлением. Обеспечь единственную активную копию данного навыка для выбранного агента. Не переустанавливай чужие навыки и не меняй общие инструкции агента без необходимости.
4. Проверь Python 3.10+, pdfplumber и pdftoppm. При необходимости создай отдельную виртуальную среду и установи зависимости из requirements.txt. Poppler устанавливай из доверенного источника для ОС, если он нужен для доступного маршрута рендера. Запиши путь к Python этой среды, чтобы агент мог запускать pdf_preflight.py позднее. Установка дополнительной CAD-системы или сторонних CAD-навыков требуется только при конкретном недостатке уже имеющихся средств; список community-кандидатов находится в references/cad-workflow.md.
5. Проверь, что агент обнаруживает навык по имени и читает связанные файлы. Выполни `pdf_preflight.py --help`; затем запусти его на небольшом тестовом PDF с JSON-отчётом и рендером всех страниц в цвете и сером. Если есть реальные чертежи, выполни их ревью без изменения исходников. Отдельно сообщи невыполненные проверки и причины.
6. Настрой использование в пределах возможностей агента: применять этот навык при выпуске и ревью рабочих чертежей из модели; профиль `workshop` по умолчанию, `formal_eskd` по требованию проекта. Сохраняй действующие требования заказчика и выбранную CAD.

В конце кратко сообщи: путь установки, commit SHA, обнаружен ли навык агентом, команды запуска проверенного Python/рендерера и результат проверки. Заверши примером запроса к `$prepare-production-drawings`. Готовность чертежей к изготовлению подтверждай инженерной и визуальной проверкой, а не одним успешным кодом скрипта.
